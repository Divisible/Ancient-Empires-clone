# Княжьи земли

Браузерный тактический прототип по мотивам Ancient Empires II: 2–4 игрока, каждый за себя, пошаговый бой без таймера, приватные комнаты и боты.

## Запуск

Нужен Node.js 22+ (проверено на 24.19). Внешних runtime-зависимостей нет.

```sh
npm test
npm start
```

Сервер слушает порт 3000 на всех интерфейсах. Для изменения: `PORT=8080 npm start`. Для игры с коллегами разместите сервер на доступном им хосте за HTTPS reverse proxy. Публичное размещение пока не выполнено.

Создайте комнату, отправьте код или приглашение. Нажмите «Начать»: свободные места займут боты. Ключ переподключения хранится в localStorage этого браузера. Ключи не передаются соперникам. Создатель может явно заменить участника ботом; участник может передать управление собой. Обратная передача в текущем матче не предусмотрена.

Матчи сохраняются после действий в `DATA_DIR` (по умолчанию `/tmp/knyaz-data`). Для постоянного размещения задайте устойчивый каталог, например `DATA_DIR=/workspace/Ancient-Empires-clone/.data npm start`. Сохранение рассчитано на один серверный процесс; горизонтальное масштабирование не поддерживается.

## Управление

Выберите своего бойца, затем видимую клетку для движения или врага для атаки. На здании доступна кнопка захвата. Чтобы нанять юнита, освободите замок, снимите выбор бойца и выберите замок. Волхв и святилища получают отдельные кнопки действий. Завершение хода — вручную.

Сервер авторитетно проверяет действия и фильтрует туман войны. Боты используют видимые цели, не получают дополнительного золота. Все юниты захватывают здания. Условия поражения: нет князя и замков; оставшаяся армия исчезает. Код новой игры не использует Java ME бинарники.

## Статус и ограничения

Реализованы все десять типов юнитов, контратаки, экономика, найм и выкуп князя, лечение, могилы и призыв, три схемы карт, святилища, туман, онлайн-комнаты, сохранение и переподключение.

Графика пока процедурная: ландшафт Canvas и условные фигуры. Короткий эффект удара не заменяет запланированные рисованные спрайты и полноценные анимации. Карты имеют равные стартовые ресурсы, но окончательная геометрия, дополнительные обходы и баланс трёхсторонней карты требуют игровых тестов. Боты базовые, не используют все способности. Средняя длительность 10–15 минут пока не подтверждена партиями. Нет аккаунтов, лобби матчмейкинга и публичного развёртывания.

## Проверки

`npm test`: тесты экономики, тумана, урона, контратаки, найма, захвата, очередности, карты и длительного выполнения ходов ботов. HTTP smoke проверяет вручную создание/вход двух участников, авторизацию, ход и повторный запрос состояния.
