# Краткий анализ

Объём: целостность ZIP, манифест, декомпиляция девяти классов CFR 0.152 и выборочная проверка общих функций. Это не полный аудит и не игровое тестирование. Обфускация делает декомпилированный текст непригодным для прямой сборки. Свидетельства: `bytecode-excerpts.txt`.

## 1. Редкий выход случайного числа за диапазон

`e.a(int,int):int`, строки CFR 103–104: `n + Math.abs(a.nextInt()) % (n2 - n)`.
При `nextInt() == Integer.MIN_VALUE` модуль остаётся отрицательным. Для диапазона [0,360) результат равен -128 вместо допустимого угла. В `g` есть реальные вызовы `e.a(360)` при инициализации эффектов. Ошибка арифметики подтверждается семантикой Java; влияние на конкретную анимацию без эмулятора не проверено. Вероятность этого значения — 1/2^32 на равномерный вызов.
Рекомендация для будущего исходного проекта: генератор ограниченного неотрицательного числа, совместимый с целевой CLDC, с проверкой границ.

## 2. Незакрытые RMS-хранилища при исключениях

Функции чтения/записи `e.a(String,int)` и `e.a(String,int,byte[])`, строки 111–130, закрывают RecordStore только после успешной операции. Исключение `getRecord`, `addRecord` или `setRecord` пропускает закрытие; аналогичная проблема в запросе свободного места, строки 133–140. Триггеры: отсутствующая запись, заполненное хранилище, ошибка RMS. Риск: накопление открытых хранилищ при повторных попытках. Факт отсутствия finally виден статически; исчерпание ресурсов на устройстве не воспроизводилось.
Рекомендация: закрывать успешно открытый RecordStore в finally.

## 3. Неверно заявленная совместимость

Манифест объявляет MIDP-1.0, но конструктор `e` вызывает Canvas.setFullScreenMode, доступный с MIDP 2.0; также используется javax.microedition.media. На устройстве только с MIDP 1.0 возможен отказ запуска/связывания. Для Nokia 6280 это не доказывает проблему, но заявленный профиль слишком широкий.

Ни один бинарник не исправлялся. Архив успешно прошёл проверку CRC; класс входа `b.class`, иконка и ресурсы присутствуют. Запуск игры и сохранения в эмуляторе не проверены. Изменения локальные, без коммита и push.
