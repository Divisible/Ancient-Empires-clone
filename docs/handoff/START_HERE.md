3. Исходники из архива либо единый файл `SOURCE_CONTEXT.txt` из пакета передачи. Последний удобен для чтения в чате; для запуска используются обычные файлы проекта.

## Точка остановки

Уже есть работающий прототип с онлайн-комнатами, серверной проверкой правил, туманом войны, наймом, десятью юнитами, святилищами и ботами. Последний завершённый этап: подсветка движения/атаки, постепенные действия ботов, плавное движение и окно победы с салютом. После него прошли 18 автоматических тестов и ручная автоматизированная проверка Chromium.

Следующий продуктовый этап — собственная графика и контент. Пока нет окончательных спрайтов, звуков, полноценной анимации боя и подтверждённого баланса карт. Размещение на Render подготовлено; публичный URL и успешное развёртывание в аккаунте пользователя в этом журнале не подтверждены.

## Как запустить исходники

Node.js 22+; проверено на 24.19.0. Зависимости устанавливать не требуется.

```sh
npm test
npm start
```

Порт по умолчанию 3000. Для постоянного хранения матчей укажите `DATA_DIR` на устойчивом диске. В архив не включены сохранения партий, ключи комнат, `.git` и временные инструменты проверки. Старый Java ME бинарник остался в репозитории как исходный материал; он не нужен для запуска новой игры и не включён в пакет исходников браузерной версии.

## Как поддерживать журнал

После каждого содержательного этапа добавлять запись по шаблону в конце `DEVELOPER_JOURNAL.md`. Также обновлять текущие правила, ограничения и список готовых материалов, если они изменились. Историю прежних решений сохранять. Дата, коммит, реально выполненные проверки и ссылка на результат важнее общих фраз «готово».

Новый чат не получает эту историю автоматически: прикрепляйте свежую копию документов. Самостоятельного фонового обновления журнала нет.
