# Публичный сервер

Игра требует одного постоянно работающего Node.js-процесса. GitHub Pages, статический хостинг и отдельные serverless-функции не подходят для текущего хранилища комнат в памяти. Браузер и API обслуживаются одним сервером и одним адресом.

## Render

В корне есть `render.yaml` для Blueprint:

1. В Render выберите **New → Blueprint**, подключите GitHub и репозиторий `Divisible/Ancient-Empires-clone`.
2. Выберите ветку с конфигурацией и проверьте план **Free**.
3. Создайте сервис и дождитесь успешного build/deploy. Проверка готовности: `/healthz` возвращает `{"status":"ok"}`.
4. Откройте выданный Render HTTPS-адрес. Создайте комнату, отправьте приглашение коллеге, проверьте вход и завершение хода из двух браузеров.

Конфигурация сама по себе не публикует сайт. Реальный адрес выдаётся после создания сервиса в аккаунте хостинга.

### Ограничения бесплатного запуска

Файлы `/tmp/knyaz-data` не являются постоянным хранилищем Render: при перезапуске, новом развёртывании или замене экземпляра матчи могут пропасть. Бесплатный сервис может засыпать; первый запрос после простоя может ждать запуска. Этот вариант подходит для знакомства с прототипом, но не гарантирует сохранность партий.

Для устойчивого размещения нужен выбранный владельцем тариф с постоянным диском либо свой сервер с постоянным каталогом. Укажите `DATA_DIR` на этом диске. Запускайте только **один** экземпляр сервера. Оплата и подключение аккаунта остаются действиями владельца.

## Свой сервер

Node.js 22+ (проверено на 24.19), репозиторий и постоянный каталог для матчей:

```sh
npm test
DATA_DIR=/var/lib/knyaz PORT=3000 npm start
```

Каталог должен быть доступен для записи пользователю приложения. Настройте процесс как службу и HTTPS reverse proxy на порт 3000. Ключи комнат и файлы матчей не публикуйте. Домен, сертификат и настройки сервера зависят от выбранного хостинга.

## Проверка после публикации

- `GET /healthz` — 200.
- Главная страница, CSS и JavaScript загружаются по HTTPS.
- Два разных браузера входят в одну комнату и видят только разрешённые туманом сведения.
- Действие одного игрока видно другому после обновления состояния.
- Перезагрузка страницы позволяет вернуться в комнату.
